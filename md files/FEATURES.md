# 🚀 Todo Management Application - Features

## 📌 Project Overview

The Todo Management Application is a Full Stack web application developed using **React.js**, **Node.js**, and **Express.js**. It enables users to efficiently manage daily tasks through a simple and responsive interface. Data is stored in a local JSON file, making the application lightweight and easy to set up.

---

# ✨ Core Features

## 📝 Create Todo

Users can create new tasks by providing:

- Title
- Description
- Priority (High, Medium, Low)

Each newly created task is automatically assigned:

- Unique ID
- Created Date
- Default Status (Pending)

---

## 📋 View Todos

The dashboard displays all available todos in attractive cards.

Each card shows:

- Title
- Description
- Priority
- Status
- Created Date

---

## ✏️ Edit Todo

Users can update:

- Title
- Description
- Priority
- Completion Status

Changes are saved immediately through the REST API.

---

## ❌ Delete Todo

Users can permanently delete any todo from the dashboard.

A confirmation dialog is displayed before deletion.

---

## ✅ Manage Status

Todos can be marked as:

- Pending
- Completed

The status is visually highlighted using colored badges.

---

# 📊 Dashboard

The application provides quick statistics:

- Total Todos
- Pending Todos
- Completed Todos

These values update automatically whenever a todo is created, updated, or deleted.

---

# 🎨 User Interface

The application features a modern and responsive design with:

- Violet-themed interface
- Dashboard summary cards
- Responsive layouts
- Hover animations
- Rounded cards and buttons
- Clean typography
- Status badges
- Priority indicators

---

# ⚙️ Backend Features

The backend provides RESTful APIs for:

- Fetching all todos
- Fetching a single todo
- Creating a todo
- Updating a todo
- Deleting a todo

Data is stored in a local JSON file without requiring a database.

---

# 💻 Frontend Features

Built with React.js and React Router.

Includes:

- Dashboard Page
- Todo Details Page
- Edit Todo Page
- Responsive Forms
- API Integration using Axios
